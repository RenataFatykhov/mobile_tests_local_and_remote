Тестовая Wikipedia 2.7.50464, английский язык, Android 14+ либо совместимый стенд. Очистку данных выполнять только у тестовой установки. Для поиска нужен интернет. Не переносить ожидаемые тексты onboarding на другую версию без сверки.
